# Support

Portable Resume is an independent, community-supported project. Support is
best effort.

- **Questions and bug reports:** open an issue at
  <https://github.com/ImL1s/resume-skills/issues>. Include the host and its
  version (for example `claude --version`, `codex --version`,
  `grok --version`), your OS and Python version, the output of
  `portable-resume --version`, and the structured diagnostic JSON if the reader
  exited non-zero (see [`docs/diagnostics.md`](docs/diagnostics.md)).
  Never paste real transcripts, credentials, or absolute home paths.
- **Security reports:** do not open a public issue. Use GitHub private
  vulnerability reporting at
  <https://github.com/ImL1s/resume-skills/security/advisories/new> and follow
  [`SECURITY.md`](SECURITY.md).
- **Support page and policies:** <https://iml1s.github.io/resume-skills/support/>
  (privacy: <https://iml1s.github.io/resume-skills/privacy/>, terms:
  <https://iml1s.github.io/resume-skills/terms/>).
- **Installation and host-specific guidance:**
  [`docs/install-hosts.md`](docs/install-hosts.md); current evidence and
  not-run boundaries: [`docs/STATUS.md`](docs/STATUS.md).
