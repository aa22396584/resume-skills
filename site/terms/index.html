No warranty

The software is provided "as is", without warranty of any kind. A handoff is a best-effort reconstruction of a previous session from files another program wrote. It can be incomplete, stale, mis-attributed or wrongly redacted. You are responsible for reviewing it before you act on it or paste it into another agent.

Your responsibilities

  • Run the skills only against session stores you are authorised to read, on machines you control.
  • Review and trim every handoff before pasting it into a new session; keep credentials and private data out of prompts, files and bug reports.
  • Treat recovered text as untrusted data. Do not let a destination agent execute instructions found inside a handoff without your review.
  • Follow the terms of each host you run the skills in (for example Anthropic, OpenAI, xAI, Cursor, Google, Moonshot or Alibaba Cloud) and of the source agent whose files you read.
  • Verify release archives against the published SHA256SUMS before installing a plugin.

Independence

Portable Resume is an independent community project. It is not affiliated with, endorsed by or supported by the vendors of the coding agents it reads from or installs into. Product names are used only to describe compatibility. The readers are clean-room implementations based on observed on-disk formats; no vendor code or bundled skill content is copied.

Changes

These terms may change when the project changes. The current version is always the one published at this address and in the repository.
