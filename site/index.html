Pick up your last session.
Offline. Inert. Local only.

Portable Resume is a set of Agent Skills for Claude Code, Codex, Grok Build, Cursor and other local coding agents. Each resume-<source> skill reads that agent's own on-disk session store and prints an inert, best-effort-redacted handoff that the fresh session summarizes and continues from. It never restores a live process.

Reads, never writes

Source session stores are opened read-only with stable, no-follow reads that fail closed on races. The reader never invokes the source agent's CLI and never modifies its files.

Local only

No network path, no credentials, no MCP server, no scheduler, no background service. The only optional child process is a trusted zstd decoder for compressed Codex rollouts.

Inert handoff

Recovered text is marked untrusted and stale, and redaction is best-effort rather than complete data-loss prevention. When a host invokes the skill, the host and its model provider receive the handoff output directly; run the reader in a terminal if you want to review it first.

Fresh session, not live restore

This is context migration. It does not resume a running process, replay tool calls, or restore host state.

How it works

One reader, one handoff

start a fresh session in the same repository → invoke resume-<source> (for example /resume-claude or $resume-codex) → the bundled reader picks the newest session for the current directory (where the source records one; see the privacy page for unscoped sources) → it prints an inert markdown handoff to stdout (or to a file you name) → the host agent reads that output as data and summarizes it for you → you verify the summary against the repository and continue

Running the reader yourself in a terminal (portable-resume <source> show latest) keeps the handoff on your machine until you decide what to paste. Inside a host skill invocation the host, and therefore its model provider, receives the handoff output directly; see Privacy.

Install

Pick your route

Any host (PyPI)

pipx install portable-resume
install-resume-skills quick-install all

Installs every destination profile into its user-global skill root. Use quick-install <host> for one host.

Claude Code

claude plugin marketplace add ImL1s/portable-resume-marketplace
claude plugin install portable-resume@portable-resume --scope user

Codex

codex plugin marketplace add ImL1s/portable-resume-marketplace
codex plugin add portable-resume@portable-resume

Grok Build

grok plugin marketplace add ImL1s/portable-resume-marketplace
grok plugin install portable-resume --trust

Cursor, Qwen Code, Kimi Code CLI and direct archive installs for every other host are documented in docs/install-hosts.md. Verify release archives against SHA256SUMS before installing a plugin.

Use

In a fresh session

/resume-claude          # Claude Code, Grok Build, Cursor and other slash-command hosts
$resume-codex           # Codex

# The skill runs only the bundled reader, for example:
python3 <skill>/scripts/run_reader.py show latest --cwd "$PWD"

The reader selects the newest session recorded for the current working directory where the source records one (sessions without a recorded directory stay eligible, and resume-openhands has no directory filter at all), prints an inert handoff, and exits. Structured diagnostics and exit codes are listed in docs/diagnostics.md.
