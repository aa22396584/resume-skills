Support

Community-supported, best effort

Before you file

  • Confirm the install: install-resume-skills verify --host <host> --scope global (or --scope project --project "$PWD") checks the recorded install plan for that host.
  • Confirm the reader: portable-resume self-check --json reports the packaged version and registries without touching any session store.
  • Read the diagnostic. A non-zero exit prints one structured JSON document on stderr; its code is explained in docs/diagnostics.md. Paths and user data never appear in it.
  • Check the host-specific notes in docs/install-hosts.md; several hosts also read Claude Code skills, so a skill can appear twice after installing to both roots.

Bug reports and questions

Open an issue at github.com/ImL1s/resume-skills/issues. Include the host and its version (claude --version, codex --version, grok --version), your OS and Python version, portable-resume --version, the exact command, and the diagnostic JSON. Never paste real transcripts, credentials or absolute home paths; a synthetic fixture from the repository's tests/fixtures tree is the right way to share a reproduction.

Security

If you believe the reader can be made to modify a source store, contact the network, execute a source agent's CLI, or leak data past its redaction and bounds, do not open a public issue. Use GitHub's private vulnerability reporting on the repository and follow SECURITY.md, which also documents the threat model and the trusted-zstd boundary.

Status and roadmap

The done/not-done ledger, including which host checks were re-run on the current release and which remain not-run, is docs/STATUS.md. Open work is tracked in the repository's issues.
